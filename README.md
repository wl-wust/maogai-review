# 毛概离线复习

一个无需后端的毛概知识库、选择题练习和主观题背诵平台。题库与页面资源全部打包在站点内，学习记录仅保存在当前浏览器。

## 公网访问

直接打开：<https://wl-wust.github.io/maogai-review/>

手机首次联网打开后，可在浏览器菜单中选择“添加到主屏幕”。页面缓存完成后，即使电脑关机、手机没有网络，也可以从主屏幕离线打开。

## 本地使用

1. 双击 `启动.bat`。
2. 浏览器打开 `http://127.0.0.1:4173`。
3. 手机与电脑连接同一局域网后，访问启动窗口显示的局域网地址。
4. 手机浏览器可通过“添加到主屏幕”安装为 PWA；完成首次缓存后，断网也能打开。

也可以在当前目录运行：

```powershell
node scripts/serve.mjs
```

## 内容

- 270 道选择题：单选 90、多选 85、判断 95，均含答案与解析。
- 25 个主观题背诵要点，包含教材打勾章节思考题，支持无答案、挖空背和完整答案。
- 17 张知识卡，包含教材打勾章节的本章小结，可搜索题目、答案、解析与知识内容。
- 收藏、错题本、正确率、最近作答和继续上次练习。

## 数据

学习记录使用浏览器 `localStorage` 保存，存储键为 `maogai-review-state-v1`。

如需从原始 Word 文档重新生成题目数据，可在项目根目录运行：

```powershell
node scripts/import-content.mjs
```

导入脚本读取 `.tmp/题库.txt`，该文件由源 Word 文档中的段落提取而成。
